# indian-numbers

Tiny helpers for showing money the way people in India read it.

```python
>>> from indian_numbers import format_inr
>>> format_inr(12345678)        # amount in paise
'₹1,23,456.78'
```

Run the tests with `python -m unittest -v`.

This repository is the demo target for
[sandboxed-coding-agent](https://github.com/AditModi/sandboxed-coding-agent).
Push it to a new GitHub repository of your own; the agent fixes issue #1 in it.
