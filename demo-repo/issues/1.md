# format_inr uses international grouping instead of Indian grouping

`format_inr(10000000)` returns `₹100,000.00`. It should return `₹1,00,000.00` (one lakh).
For crores it is also wrong: `format_inr(1234567890)` should be `₹1,23,45,678.90`.

The tests in `tests/test_money.py` already describe the right behaviour and fail today.
